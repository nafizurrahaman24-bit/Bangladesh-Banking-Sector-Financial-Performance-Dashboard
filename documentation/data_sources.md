# Data Sources

## Overview

This project uses publicly reported financial information to compare the performance of 11 selected Bangladeshi commercial banks over 2021–2025.

## Primary Source Categories

- Annual reports of the selected banks
- Published financial statements
- Bank financial disclosures
- Relevant Bangladesh banking and financial-market disclosures
- Market-data sources used for P/B ratio, market value, and related indicators

## Reproducibility

The repository should preserve the cleaned dataset, source links, methodology, data dictionary, and DAX measures so dashboard results can be traced back to the underlying financial information.
