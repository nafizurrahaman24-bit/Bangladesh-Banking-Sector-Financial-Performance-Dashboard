## Aggregation Rules

The dashboard primarily uses **Average** aggregation for annual bank-level ratio indicators.

Average values represent the mean of available annual reported observations within the selected filter context. They are not automatically weighted sector-wide ratios.

## Data Quality Checks

Before publication, verify:

- No duplicate bank-year records.
- Bank names are standardized.
- Ownership categories are standardized.
- Year values are correctly mapped.
- Percentage fields use consistent scaling.
- Monetary fields use consistent units.
- Missing values are not incorrectly converted to zero.
- Source values can be traced to the source register.
